## 🔄 更新のしかた

ClaudeCodeでこのフォルダを開き、変更内容を伝えるだけ。
Claudeが `index.html` を編集 → GitHubへpush → 数分で公開ページに反映されます。

手動でやる場合：

```bash
git add -A && git commit -m "更新内容" && git push origin main
```

---

## 🛟 フォルダが消えた・PCが壊れたとき

**データはGitHub上に保管されているので、必ず復旧できます。**

`復元.bat` をダブルクリックするか、以下を実行：

```bash
git clone https://github.com/ytomde15/okinawa2026.git
```

※ 復元後にpush（更新）したい場合は、ClaudeCodeに「pushできるようにして」と伝えれば認証を再設定します。
